# 消费记录 ExpenseTrack

**中文** | [English](README.en.md)

一个只在本机运行的 Android 记账 App：自动读取**中国建设银行**的动账通知，记下每一笔支出和收入，按日 / 周 / 月 / 年统计，还可以让 DeepSeek 帮你分析钱花在了哪里。

- 不需要注册账号，所有记录只保存在手机上。
- 安装包约 1.3 MB，支持 Android 8.0 及以上。

## 功能

1. **自动记账**：建行 App 推送、95533 短信、建行微信公众号的通知都能识别。
   - 支出：消费、支付、支出、扣款、取款、转出、缴费。
   - 收入：收入、存入、转入、入账、汇入；退款、退货、撤销、冲正也算收入。
   - 信用卡还款只是自己账户之间转钱，会被忽略。
   - 同一笔交易同时收到 App 推送和短信时，只记一次。
2. **编辑记录**：点一笔记录，可以写备注（买了什么），金额或收支类型识别错了也能改。另外支持手动记账和删除。
3. **统计**：按日 / 周 / 月 / 年查看。月视图是日历热力图，颜色越深花得越多；周、年视图是柱状图，点日期或柱子可以下钻。有收入时会显示「收入」和「结余」；日历、柱状图和 AI 分析只统计支出。
4. **AI 消费分析（可选）**：填入自己的 DeepSeek API Key 后，按备注给每笔消费分类，生成环形占比图，加上一句总结、两条观察和一条建议。每个时间段的结果保存在本机，记录有变化时会提示结果可能已过时。
5. **每日小结**：每天在设定的时间（默认 19:00）推送当天花了多少、收入多少。
6. **防止漏记**：常驻通知「自动记账中 · 今日支出」，降低被系统清理的概率，被划掉后会自动重新出现。即使 App 被清掉，重新打开一次也会自动恢复捕获，并补记通知栏里还留着的建行通知。

## 安装

1. 从 [Releases](https://github.com/6666gs/ExpenceTrack_CCB/releases/latest) 下载最新的 `ExpenseTrack-x.y.apk`，在手机上打开安装，系统提示时允许「安装未知来源应用」。
   - 通过**微信**发送的安装包会被改名成 `.apk.1`，无法直接安装。先保存到手机，用「文件管理」把文件名末尾的 `.1` 删掉再安装；也可以压缩成 zip 再发，或改用 QQ、网盘传输。
2. 打开 App，按「记录」页顶部的提示开启「读取通知」等权限。
3. 到「设置 › 后台运行 · 防止漏记」，按当前机型列出的步骤操作。每一步都有按钮，可以直达对应的系统页面。

## 权限说明

App **不申请**通话、联系人、短信、定位、相机、麦克风、存储等权限。

**需要你手动开启的：**

| 权限 | 是否必须 | 用途 |
|---|---|---|
| 读取通知（通知使用权） | **必须** | 识别建行的动账通知。不开就无法自动记账 |
| 发送通知 | 建议 | 每日小结和常驻的「自动记账中」 |
| 闹钟和提醒（精确闹钟） | 可选 | 每日小结准点送达，不开可能晚几分钟 |

**安装时自动获得、无需操作的：**

| 权限 | 用途 |
|---|---|
| 网络 | 只在点「开始分析」或「测试连接」时访问 DeepSeek |
| 开机启动 | 重启后重新设定每日小结的提醒时间 |
| 前台服务 | 让「自动记账中」常驻，防止被清理 |

**关于「读取通知」的系统警告**：开启时，系统会提示该应用"能读取所有通知，包括联系人姓名、短信内容"等。这个权限本身就是能看到所有通知，系统没法只开放某一个 App 的通知，所以所有记账类、手环类应用都会弹同样的提示。本 App 对每条通知只在本机判断一下，不是建行的直接丢弃，不保存、不上传。

## 隐私

- 记录保存在本机数据库里，禁止云备份和换机迁移导出。
- 只有点「开始分析」或「测试连接」时才联网。分析时只把所选时间段每笔消费的金额、时间、备注和商户名发给 DeepSeek，银行通知原文（可能含卡号尾号）不会发送。
- DeepSeek API Key 用 Android Keystore 加密后保存在本机。
- 只允许 HTTPS，正式版关闭调试。

## 国产手机必看（vivo / 小米 / OPPO / 华为）

这些系统会主动清理后台，导致漏记和收不到提醒。App 的「设置」页会按机型列出以下步骤：

1. **读取通知**：必须开。
2. **自启动**：例如 vivo 在「i管家 › 应用管理 › 权限管理 › 自启动」。
3. **后台耗电**：改成「允许后台高耗电」或「无限制」。
4. **建行 App 通知**：建行 App 自己的消息推送和系统通知都要开着，否则没有通知可读。
5. **锁定在后台**：在最近任务里锁定「消费记录」，一键清理时会跳过它。
6. **常驻通知**：默认开启，可以在同一页关闭。

已经从通知栏划掉的通知读不回来，所以建议把上面几步都设置好。

## 从源码构建

- 推荐用 **Android Studio**（Ladybug 或更新版本）打开本目录，同步后点 Run。
- 命令行构建需要 JDK 17–21（Gradle 8.9 不支持更新的 JDK）。仓库里没有提交 wrapper 的 jar，先在 Android Studio 里同步一次，或者执行 `gradle wrapper`。之后：

```bash
./gradlew testDebugUnitTest assembleRelease
```

- 安装包输出在 `app/build/outputs/apk/release/app-release.apk`。
- 正式版目前用调试证书签名，适合私下分发；上架应用商店前要换成自己的发布证书。

## 某条通知没被识别？

识别规则在 [`CcbNotificationParser.kt`](app/src/main/java/com/expensetrack/parser/CcbNotificationParser.kt)。把那条通知的原文（卡号、余额请打码）作为新用例加进 [`CcbNotificationParserTest.kt`](app/src/test/java/com/expensetrack/parser/CcbNotificationParserTest.kt)，再调整规则即可，也欢迎提 Issue 附上打码后的原文。

## 代码结构

```
parser/    CcbNotificationParser      通知文本 → 金额 / 商户 / 收支（纯函数，有单测）
capture/   BankNotificationListener   通知监听；常驻通知、自动重连、补记
data/      Room 实体、DAO、仓库、去重规则、数据库迁移
summary/   AlarmManager 定时、开机重排、每日小结通知
stats/     StatsPeriod / StatsCalculator  日周月年区间与汇总（纯函数，有单测）
ai/        DeepSeekClient、SpendingAnalysisPrompt、AnalysisCodec  提示词、解析与保存（有单测）
setup/     RomGuide、SetupIntents     各品牌后台设置的路径与跳转
settings/  SettingsStore、SecretCipher（Keystore 加密 API Key）
ui/        Compose 界面：记录 / 统计 / 设置
```
